# showfire-legal

The privacy policy and support page for ShowFire, the cue player and show controller for iPad and Mac. Published with GitHub Pages, and linked from App Store Connect (privacy policy URL, support URL) and the app's TestFlight information.

- `index.html` — support page
- `privacy.html` — privacy policy
- `style.css` — shared styles (light and dark)

Plain HTML, no build step. To publish: GitHub → Settings → Pages → Deploy from a branch → `main`, `/ (root)`. The pages then live at `https://magnusjune.github.io/showfire-legal/`.

When the app starts collecting or sending anything new, update `privacy.html` and its effective date, and the App Privacy answers in App Store Connect.
